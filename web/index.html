Line speeds by line

Throughput comes from the line speed and the wire geometry: kg/h = mm/s × 3.6 × (π/4 · d²) × 7,850 kg/m³. An empty cell means that line has no speed for that diameter, so it does not run it. The fastest lines for each diameter are in green.
